# ADR-002: Go for the gateway, Python for ingestion

- **Status:** accepted (2026-11-24)
- **Context:** Conduit is not an agent harness. It never runs a model loop; agents (Tracebase's harness, Claude, Cursor) call it. It is a governed tool gateway: every MCP call passes the same eight stages (authenticate, tenant scope, grant check, validate args, rate limit, risk gate, execute, audit). That hot path is concurrent, latency-sensitive proxy work, the category Go was built for (Traefik, Kong and most API gateways are Go). Ingestion is the opposite: batch work dominated by PDF extraction and chunking, where Python's libraries (PyMuPDF) are far ahead. The FastAPI service holds only `/me` today, so changing the gateway's language is cheap now and expensive later.
- **Decision:** the gateway (MCP server, eight-stage pipeline, admin REST API, machine-auth issuance, retrieval at query time) is a Go service. Ingestion (extract, chunk, embed, quality report) is a Python worker with no public HTTP surface. The two share Postgres and nothing else: the gateway enqueues `ingest_jobs` rows, the worker claims them with `FOR UPDATE SKIP LOCKED` and writes `chunks`. Tracebase stays Python end to end (its bottleneck is the model call, and its value is evals and structured outputs).
- **Consequences:** one static binary in a small distroless image with fast Cloud Run cold starts on the path agents wait on; goroutines per call without an event-loop to block. Two languages in one repo: two toolchains in CI, and two contracts that must not drift (schema, and embedding model + text-search config, see `docs/GO-GATEWAY-PLAN.md`). Conduit's API no longer takes the kit's Python `api/` files; the Go gateway ports `/me` and its token tests.
- **Risk and fallback:** the official MCP Go SDK is the one unproven piece. A 90-minute spike (Streamable HTTP server, `tools/list` per agent, a real client connecting) runs first on Day 2. If it fails, the MCP endpoint stays in Python behind the Go pipeline for the week, and the decision is revisited.
- **Revisit if:** the MCP Go SDK spike fails, or ingestion needs to run inline with a request (then the boundary moves).
